# 🃏 Flashcards App

Aplicação web interativa de cartões de memória (flashcards) desenvolvida com React, TypeScript e Vite, projetada para auxiliar no processo de fixação de estudos e memorização com sistema de pontuação e estatísticas de desempenho.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando a seguinte stack:

- **React**
- **TypeScript**
- **Vite**
- **CSS**
- **ESLint**

## ✨ Funcionalidades

- **Sorteio Dinâmico:** Apresentação randômica de perguntas e alternativas para evitar repetição mecânica.
- **Feedback Imediato:** Validação instantânea da resposta selecionada (correta/incorreta).
- **Controle de Sessão:** Ciclos configurados por sessões (ex: 4 perguntas por ciclo).
- **Painel de Desempenho:** Tela final com resumo detalhado contendo a quantidade de acertos e o percentual de aproveitamento (`%`).
- **Reinício Rápido:** Opção para reiniciar a sessão a qualquer momento para praticar novamente.

## 📦 Como Executar o Projeto

Certifique-se de ter o **Node.js** instalado em sua máquina.

1. Clone o repositório:
   ```bash
   git clone https://github.com/wiarley-sena/flash-card.git
   ```
2. entre na pasta do projeto:
  ```bash
  cd flash-card
  ```
3. instale dependências:
  ```bash
  npm install
  ```
4. execute o projeto em modo de desenvolvimento:
  ``` bash
  npm run dev
  ```
5. acesse no navegador através do link fornecido pelo vite (geralmente http://localhost:5173)
